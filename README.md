# Weather Data Pipeline & Dashboard

An automated Python data pipeline that collects current weather data for Delhi, Mumbai, and Bengaluru, combines it with demographic data, and displays the results in an interactive Streamlit dashboard.

## Features

- Fetches current temperature and relative humidity using the Open-Meteo API.
- Stores weather readings in CSV files.
- Combines weather data with city demographic data using Pandas.
- Removes duplicate city/time records during transformation.
- Supports scheduled execution using cron.
- Provides an interactive Streamlit dashboard.
- Includes city and date filters, temperature charts, and a data table.
- Includes basic automated tests using pytest.

## Setup

Clone the repository:

```bash
git clone https://github.com/HarshJha2804/Weather_App.git
cd Weather_App
```

Create and activate a virtual environment on Linux/WSL:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Pipeline

```bash
python src/main.py
```

## Run the Dashboard

```bash
streamlit run app.py
```

Open the local URL shown in your terminal, usually `http://localhost:8501`.

## Run Tests

```bash
python -m pytest -v
```

## Data Source

Weather data is retrieved from the [Open-Meteo API](https://open-meteo.com/).

## Notes

- The dashboard requires `data/combined_data.csv`, generated by the pipeline.
- The cron schedule must be configured separately on the machine running the pipeline.
- Weather data reflects the readings returned by the API when the pipeline runs.
